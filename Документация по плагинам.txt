# Документация по плагинам (Lua)

Система плагинов позволяет расширять и изменять функциональность приложения "Маська", используя скрипты на языке Lua. Каждый раз при загрузке страницы сайта в WebView, все включенные плагины выполняются в фоновом режиме.

## Поддерживаемые функции

Через глобальный объект `app` вашему скрипту доступны следующие методы для взаимодействия с приложением и страницей:

1. `app:executeJs(jsCode)`
   Выполняет произвольный JavaScript код на текущей странице сайта. Это основной способ изменить внешний вид, добавить элементы или изменить логику сайта.
   
   **Пример:**
   ```lua
   app:executeJs("document.body.style.backgroundColor = 'black';")
   ```

2. `app:showToast(message)`
   Показывает нативное всплывающее уведомление (Toast) на экране устройства Android.
   
   **Пример:**
   ```lua
   app:showToast("Плагин успешно загружен!")
   ```

## Формат плагина

Чтобы плагин корректно отображался в приложении (название, описание, иконка), необходимо указать метаданные в комментариях **в самом начале файла**. Приложение ищет следующие специальные теги:

- `-- @name` : Название плагина. Задает имя, которое будет отображаться в списке плагинов.
- `-- @description` : Краткое описание плагина. Помогает пользователям понять, что делает расширение.
- `-- @icon` : Иконка плагина. Может быть одним из следующих вариантов:
    1. **Эмодзи:** Просто вставьте любой эмодзи (например, 🌙, 🚀, 🧩).
    2. **URL картинки:** Вставьте прямую ссылку на изображение, начинающуюся с `http://` или `https://` (например, `https://s.fotora.ru/abc45eae0487e11c.png`).
    3. **Base64 картинка:** Вставьте код изображения в формате Data URI, начинающийся с `data:image/` (например, `data:image/png;base64,iVBORw0KGgo...`).

**Полный пример простого плагина с иконкой-картинкой (файл my_plugin.lua):**

```lua
-- @name Тёмный фон
-- @description Делает фон страницы тёмным
-- @icon https://s.fotora.ru/abc45eae0487e11c.png

-- Показываем уведомление
app:showToast("Включаем тёмный фон...")

-- Применяем CSS через JavaScript
app:executeJs("document.body.style.backgroundColor = '#121212';")
```

## Добавление плагина

- **Из файла:** Нажмите кнопку `+` в правом нижнем углу меню плагинов, чтобы загрузить файл с расширением `.lua` или `.txt`.
- **Из магазина:** Нажмите на иконку 🛒 магазина в верхнем меню. Плагины из магазина устанавливаются в один клик.

## Магазин плагинов
Магазин загружает список доступных плагинов из GitHub репозитория `shop.json`. Формат файла магазина:

```json
[
  {
    "name": "Тестовое расширение",
    "icon": "https://s.fotora.ru/abc45eae0487e11c.png",
    "description": "Описание плагина",
    "code": "app:executeJs('alert(1)');"
  }
]
```
